# OutreachGain

AI-powered personalized cold email generator. Upload leads (CSV), get personalized emails in seconds.

## Quick Start

```bash
npm install
npm run dev
```

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Claude API
- Vercel deployment

## Features

- CSV upload (name, company, role)
- AI-generated personalized emails
- Free: 50 emails/month
- Paid: ₹499/month unlimited
- Download results as CSV

## Environment

Create `.env.local`:
```
CLAUDE_API_KEY=sk_...
```
